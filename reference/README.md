# Historical reference outputs

`original_outputs/` contains the essential saved results from the author's original directory export. They support quick historical report reconstruction and independent checks of partitions/stability. Redundant export copies and development checkpoints not needed by those checks were omitted from this publication package.

These files remain the historical baseline. They were not overwritten with values transcribed from later Console output. The later technology, health and insurance reruns are documented in `docs/REPRODUCTION_STATUS.md`. Newly generated full result files and complete fit objects are written under `outputs/` when fit mode is run.

Historical report mode may show NA for a selected-run parameter absent from the original saved object. The subsequent fresh smaller-technology rerun established its selected beta as 0.8434849. Consult the latest rerun documentation or newly generated fit outputs when preparing updated tables.
